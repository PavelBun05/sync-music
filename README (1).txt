SYNC MUSIC — пользовательские избранные, друзья, музыка сервера и общие альбомы

УСТАНОВКА
1. Сделай резервную копию старой папки проекта.
2. Распакуй архив и замени файлы проекта файлами из папки sync-music-redesign.
3. Открой терминал в этой папке.
4. Выполни: npm install
5. Выполни: npm start
6. Открой: http://localhost:3000

МУЗЫКА НА СЕРВЕРЕ
Положи свои аудиофайлы в папку public/music.
Поддерживаются: MP3, WAV, OGG, M4A, AAC, FLAC.
Каталог на главной странице формируется автоматически по реальным файлам в этой папке.
Демонстрационного каталога и предустановленных песен больше нет. Если папка пуста, каталог будет пустым и покажет подсказку.
Название трека берётся из имени файла. Например: Kino - Gruppa krovi.mp3.

ИЗБРАННОЕ
У каждого аккаунта свой список избранных песен. Нажатие на название песни в каталоге добавляет её в избранное. Кнопка с сердцем позволяет добавить или убрать песню. Данные хранятся на сервере.

ДРУЗЬЯ
В разделе «Создать одну волну» введи точный логин другого зарегистрированного пользователя и нажми «Добавить друга». Добавление взаимное: вы оба появитесь в списках друзей. После этого можно выбрать друга и просматривать его избранные песни.

КОМНАТА
Нажми на имя участника комнаты, чтобы посмотреть его избранное. Список участников комнаты и управление воспроизведением остаются синхронизированными. Управлять плеером может администратор комнаты.

ОБЩИЕ АЛЬБОМЫ
Введи собственное название, выбери друга и тип:
- Объединённые списки музыки — все уникальные песни из избранного обоих пользователей.
- Только совпадающие песни — песни, которые есть в избранном у обоих.
- Только музыка друга — весь список избранного выбранного друга.
Созданный альбом появляется у тебя и у выбранного друга. Удалить его может создатель.

ХРАНЕНИЕ ДАННЫХ
После первого запуска сервер создаст папку data:
- users.json — аккаунты (пароли в виде хешей);
- user-data.json — избранное пользователей;
- friends.json — связи друзей;
- albums.json — общие альбомы;
- .token-secret — секрет для токенов авторизации.
Не удаляй папку data, если хочешь сохранить пользователей, избранное, друзей и альбомы.

ВАЖНО
Это учебный проект. Для публичного размещения в интернете потребуется дополнительно настроить HTTPS, резервное копирование, ограничения запросов и более надёжное хранилище данных.
